## ⚠️ Текущий статус фотографий

**Статус**: ✅ Сайт работает с placeholder-изображениями

Все изображения временно заменены на placeholder'ы (заглушки) через сервис placehold.co.

### Что нужно сделать:

1. **Получить 8 фотографий** от клиента (список в `photos/README.md`)
2. **Сохранить в папку** `photos/`
3. **Запустить скрипт** замены:
   ```bash
   ./replace-placeholders.sh
   ```

Подробная инструкция: [PHOTO-REPLACEMENT-GUIDE.md](PHOTO-REPLACEMENT-GUIDE.md)
