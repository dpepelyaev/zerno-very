# Сайт «Зерно Веры»

Православный семейный центр при Свято-Екатерининском кафедральном соборе г. Краснодара.

## 🚀 Быстрый старт

### Локальный запуск

1. **Открыть в браузере:**
   ```bash
   open index.html
   ```
   
   Или перетащите файл `index.html` в окно браузера.

2. **Запустить локальный сервер (рекомендуется):**
   ```bash
   # Вариант 1: Python
   python3 -m http.server 8000
   
   # Вариант 2: Node.js (если установлен npx)
   npx serve .
   
   # Вариант 3: PHP
   php -S localhost:8000
   ```
   
   Затем откройте в браузере: http://localhost:8000

## 🚢 Деплой на хостинг

### Вариант 1: Через FTP
1. Подключитесь к хостингу через FileZilla/CyberDuck
2. Загрузите ВСЕ файлы из папки `zerno-very/` в корень сайта
3. Убедитесь, что `index.html` находится в корне

### Вариант 2: Через SSH
```bash
# Архивируем сайт
cd /Users/pepden/Проекты/zerno-very/
tar -czf zerno-very-site.tar.gz index.html styles.css script.js robots.txt sitemap.xml images/ фото/

# Загружаем на сервер (замените данные хостинга)
scp zerno-very-site.tar.gz user@зерно-веры.рф:/var/www/html/

# На сервере распаковываем
ssh user@зерно-веры.рф
cd /var/www/html/
tar -xzf zerno-very-site.tar.gz
rm zerno-very-site.tar.gz
```

### Проверка после деплоя:
1. Откройте https://зерно-веры.рф/ в браузере
2. Проверьте работу слайдера
3. Проверьте мобильное меню на телефоне
4. Убедитесь, что все фото загружаются
5. Протестируйте кнопку «Поддержать центр»
