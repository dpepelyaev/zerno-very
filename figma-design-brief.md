## 🎨 Дизайн-система

### Цветовая палитра

```
Основные цвета:
├── Background (#E8DCC8)      — Светлый бежевый (основной фон)
├── Surface (#D4C4A8)         — Тёплый бежевый (карточки, блоки)
├── Primary (#7D8B5E)         — Оливковый (росток, листья)
├── Primary Dark (#2D4A3E)    — Тёмно-зелёный (заголовки)
├── Accent Gold (#C9A227)     — Охра (декор, зерно)
├── CTA Red (#B22222)         — Красный (кнопки призыва)
└── White (#FFFFFF)           — Белый (контраст, карточки)

Дополнительные:
├── Text Primary (#1A1A1A)    — Почти чёрный (основной текст)
├── Text Secondary (#4A4A4A)  — Серый (описания)
└── Border (#D4C4A8)          — Границы карточек
```

**Как применить в Figma:**
1. Создайте Color Styles для каждого цвета
2. Назовите их: `Primary/Olive`, `Surface/Beige`, `CTA/Red`
3. Используйте только эти стили во всём дизайне

---

### Типографика

**Шрифты для импорта:**
- **Заголовки:** Cormorant Garamond (Bold 700, SemiBold 600)
- **Текст:** PT Serif (Regular 400, Medium 500)
- **Альтернатива:** Old Standard TT + Open Sans

**Текстовые стили:**

```
H1 — Главный заголовок
├── Шрифт: Cormorant Garamond Bold 700
├── Размер: 64px (Desktop) / 36px (Mobile)
├── Line height: 1.2 (120%)
└── Цвет: Primary Dark (#2D4A3E)

H2 — Заголовки секций
├── Шрифт: Cormorant Garamond SemiBold 600
├── Размер: 48px (Desktop) / 28px (Mobile)
├── Line height: 1.3 (130%)
└── Цвет: Primary Dark (#2D4A3E)

H3 — Подзаголовки
├── Шрифт: Cormorant Garamond SemiBold 600
├── Размер: 32px (Desktop) / 24px (Mobile)
├── Line height: 1.4 (140%)
└── Цвет: Primary (#7D8B5E)

Body Large — Лид-текст
├── Шрифт: PT Serif Regular 400
├── Размер: 20px
├── Line height: 1.6 (160%)
└── Цвет: Text Primary (#1A1A1A)

Body — Основной текст
├── Шрифт: PT Serif Regular 400
├── Размер: 16px
├── Line height: 1.6 (160%)
└── Цвет: Text Primary (#1A1A1A)

Body Small — Описания
├── Шрифт: PT Serif Regular 400
├── Размер: 14px
├── Line height: 1.5 (150%)
└── Цвет: Text Secondary (#4A4A4A)

Quote — Цитаты
├── Шрифт: Cormorant Garamond Italic 600
├── Размер: 28px (Desktop) / 20px (Mobile)
├── Line height: 1.5 (150%)
└── Цвет: Primary Dark (#2D4A3E)
```

**Как создать в Figma:**
1. Плагин: Font Scale (автоматическая типографическая шкала)
2. Создайте Text Styles для каждого стиля
3. Настройте Auto Layout для текстовых блоков

---

### Spacing System (отступы)

```
4px  — xs   (Tiny)
8px  — sm   (Иконки, мелкие детали)
16px — md   (Между элементами)
24px — lg   (Внутри блоков)
32px — xl   (Между группами)
48px — 2xl  (Между подсекциями)
64px — 3xl  (Между секциями Desktop)
40px — 3xl  (Между секциями Mobile)
```

**Как применить:**
- Auto Layout Gap: используйте только значения из системы
- Padding: 24px (карточки), 48px (секции Desktop), 24px (секции Mobile)

---

### Layout Grid (сетка)

**Desktop (1440px):**
```
Container: 1280px (max-width)
Columns: 12
Gutter: 24px
Margin: 80px (left/right)
```

**Tablet (768px):**
```
Container: 720px
Columns: 8
Gutter: 16px
Margin: 24px
```

**Mobile (375px):**
```
Container: 100%
Columns: 4
Gutter: 16px
Margin: 16px
```

**Как настроить:**
1. View → Layout Grids
2. Создайте 3 фрейма: Desktop, Tablet, Mobile
3. Примените соответствующие сетки

## 🔧 Компоненты для создания

- Варианты: Default, Hover, Pressed, Disabled

- Properties: Icon, Title, Age, Description

- Properties: Quote (text), Author (text)

### Input
- Properties: Placeholder, Label, Error state

- Для возрастов: "1,5–4", "4+", "7–16"

## 🎨 Декоративные элементы

### Акварельные текстуры
- Плагин: Artboard Studio → Watercolor Textures
- Opacity: 10-30%
- Blend mode: Multiply

### Растительные узоры
- Iconify → "wheat", "leaf", "grain"
- Цвет: #7D8B5E или #C9A227
- Разместить по углам секций

### Православные элементы
- Тонкие кресты (как в логотипе)
- Купола храма (силуэты, низкая непрозрачность)
- Колосья

## 📦 Экспорт для разработки

После завершения дизайна:

1. **Dev Mode:**
   - Переключитесь в Dev Mode (правый верхний угол)
   - Разработчики смогут инспектировать CSS

2. **Экспорт ассетов:**
   - Логотипы: SVG
   - Иконки: SVG
   - Фото: WebP (качество 80%)
   - Декор: PNG с прозрачностью

3. **Передача:**
   - Поделитесь ссылкой на Figma (View access)
   - Экспортируйте Style Guide (плагин)

---

**Время на дизайн:** ~8-12 часов работы
**Следующий шаг:** Согласование с клиентом → Вёрстка → Интеграция
