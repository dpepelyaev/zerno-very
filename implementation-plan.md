# План создания лендинга
# Семейный центр «Зерно веры»

---

## О проекте

**Заказчик:** АНО «Семейный центр «Зерно Веры»

**Цель сайта:**
- Привлечение пожертвований на социальные проекты центра
- Запись новых семей на экскурсию и программы

**Тип сайта:** Одностраничный лендинг (Landing Page)

---

### Этап 1. Сбор информации ✅ Завершён

|--------|--------|

| Получить буклеты центра | ✅ |

### Этап 2. Сбор материалов от клиента ⏳ В процессе

Для продолжения работы необходимо получить:

| Материал | Описание | Статус |
|----------|----------|--------|
| **Фотографии** | 10 качественных горизонтальных фото для карусели | ⏳ |
| **Портрет основателей** | Семейное фото м. Светланы и о. Андрея | ⏳ |
| **Фото концертов** | 3-5 фото с мероприятий в зале на Красной | ⏳ |
| **Договор о поддержке** | PDF для скачивания юр. лицами | ⏳ |
| **Реквизиты АНО** | ИНН, ОГРН, расчётный счёт, банк | ⏳ |
| **Отзывы родителей** | 3-4 текстовых отзыва | ⏳ |
| **Уточнение** | Митрополит Исидор или Василий? | ⏳ |
| **Логотип** | В векторном формате (SVG) | ⏳ |

### Этап 3. Написание текстов

После получения материалов будут написаны тексты для всех блоков сайта:

| Блок | Что будет написано |
|------|-------------------|

| О центре | Краткое описание миссии, история |

### Этап 4. Дизайн

#### 4.1. Создание прототипа
- Структура всех блоков
- Расположение элементов
- Мобильная версия

#### 4.2. Визуальный дизайн
- Применение цветовой палитры (бежевый, зелёный, охра)

#### 4.3. Согласование
- Презентация дизайна клиенту
- Внесение правок (до 2 раундов)

### Этап 5. Разработка (вёрстка)

| Задача | Описание |
|--------|----------|
| **Адаптивная вёрстка** | Сайт будет корректно отображаться на компьютерах, планшетах и телефонах |
| **Оптимизация скорости** | Загрузка страницы менее 3 секунд |
| **SEO-оптимизация** | Правильные заголовки, описания, alt-теги для поиска |
| **Карусель фотографий** | Автоматическая и ручная прокрутка |
| **Формы** | Форма записи на экскурсию, форма пожертвования |

---

### Этап 6. Подключение платежей

#### Варианты приёма пожертвований:

**Для физических лиц:**
| Сервис | Комиссия | Особенности |
|--------|----------|-------------|
| ЮMoney | 1-3% | Простое подключение, популярен в РФ |
| CloudPayments | 2.5-3.5% | Рекуррентные платежи (ежемесячные) |
| Тинькофф | 2.49% | Надёжный, быстрый вывод |

**Для юридических лиц:**
- Кнопка «Скачать договор» (PDF)
- Реквизиты для перевода

#### Функции формы пожертвования:
- Выбор суммы: 100, 300, 500, 1000 руб.
- Ввод произвольной суммы
- Опция ежемесячного списания
- Безопасная оплата картой

## Визуальный стиль

### Цветовая палитра

| Цвет | Где используется |
|------|------------------|
| **Светлый бежевый** #E8DCC8 | Основной фон |
| **Тёплый бежевый** #D4C4A8 | Фон блоков |
| **Оливковый** #7D8B5E | Декор, иконки |
| **Тёмно-зелёный** #2D4A3E | Заголовки |
| **Охра** #C9A227 | Акценты (зерно) |
| **Красный** #B22222 | Кнопки |

### Стилистика
- Акварельные текстуры
- Плавные линии, растительные узоры
- Стилизованная хохлома (современная)
- Образы: зерно, колосок, семья, храм
