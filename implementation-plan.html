Этап 4. Дизайн

4.1. Создание прототипа

  • Структура всех блоков
  • Расположение элементов
  • Мобильная версия

4.2. Визуальный дизайн

  • Применение цветовой палитры (бежевый, зелёный, охра)
  • Подбор шрифтов (славянский стиль для заголовков)
  • Создание декоративных элементов (колосья, завитки)
  • Обработка фотографий

4.3. Согласование

  • Презентация дизайна клиенту
  • Внесение правок (до 2 раундов)
  • Финальное утверждение

Что получит центр

Готовый сайт:

  • Адаптивный лендинг (компьютер + телефон)
  • Форма записи на экскурсию
  • Приём онлайн-пожертвований
  • Скачивание договора для юр. лиц
  • Карусель с фотографиями
  • Контакты и карта

Дополнительно:

  • Подключение Яндекс.Метрики
  • SSL-сертификат (безопасность)
  • Инструкция по редактированию
  • Консультации после запуска

Что нужно от центра сейчас

  1. Фотографии — 10 шт. для карусели + концерты + портрет основателей
  2. Реквизиты АНО — для подключения платежей
  3. Договор о поддержке — PDF для скачивания
  4. Отзывы — 3-4 текста от родителей
  5. Уточнить — действующий митрополит (Исидор или Василий)
  6. Логотип — в векторном формате (если есть)
